# App Religião

Aplicativo móvel de estudo inspirado na estrutura do App ENCCEJA.

## V1
- Shorts de questões
- Leitura
- Temas
- Desempenho
- Favoritos
- Treino
- Progresso salvo localmente
- PWA instalável no celular

Os bancos de questões e leitura começam vazios para evitar conteúdo religioso inventado. Eles serão alimentados a partir dos materiais fornecidos pelo usuário.
